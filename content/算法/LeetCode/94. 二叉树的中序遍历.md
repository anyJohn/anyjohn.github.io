# 94. 二叉树的中序遍历

Origin: [LeetCode 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

## 题目描述

给定一个二叉树的根节点 `root`，返回它的中序遍历结果。

## 示例

Input: `root = [1, null, 2, 3]`
Output: `[1, 3, 2]`

```
    1
     \
      2
     /
    3
```

Input: `root = []`
Output: `[]`

Input: `root = [1]`
Output: `[1]`

## 约束

- 树中节点数目范围是 [0, 100]
- -100 <= Node.val <= 100

## 关键信息

- 中序遍历：左 → 根 → 右
- 递归最简单，迭代用栈
- 二叉树节点结构：val + left + right
